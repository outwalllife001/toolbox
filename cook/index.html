常见问题

菜谱是哪来的？靠谱吗？

全部来自 GitHub 上的开源菜谱《程序员做饭指南》（HowToCook）：一群程序员嫌网上的菜谱「少许、适量」说不清，自己写了一套带克数、毫升、分钟的做法，几百人一起改了几年。本页收了其中 300 多道（饮品、酱料没收），做法原文照搬，没有改动；每道菜下面都有原文链接。

「现在就能做」是怎么算的？

每道菜的「必备原料」里，主料（菜、肉、蛋、主食）你都勾上了，就算能做；油、盐、酱油、醋、糖、葱姜蒜、淀粉、料酒这些常用调料默认你家有。八角、豆瓣酱这类不一定家家都有的，会在菜名下面写「另需」。原菜谱里标了「可选」的不算。归类是程序做的，偶尔会不准，点开菜谱能看到原文写的全部原料，以它为准。

为什么勾了「猪肉」，红烧肉、小炒肉都出来了？

为了少点几下，五花肉、里脊、肉末都算「猪肉」，各种鱼都算「鱼」，青椒、尖椒都算「青椒」。具体要哪个部位，点开菜谱看原料。

卡路里准吗？

是原菜谱作者估算的一份的热量，只能当参考，别拿来做严格的饮食控制。

我点的食材会上传吗？

不会。菜谱数据一次下到你手机里（不到 1MB），勾选、匹配、排菜单都在浏览器里算，勾过的食材只存在你自己的手机上。

做菜时屏幕老是自己灭？

打开菜谱后点「屏幕常亮」，做菜时就不会熄屏（部分浏览器不支持）。做完一步点一下那一步，会划掉；步骤里写了时间的，点旁边的计时按钮。
